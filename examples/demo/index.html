Free, with honest limits.

“Unlimited” means no cap on total sites — not unlimited bandwidth or infinite new sites per day.

25new sites per UTC day, per registered account
∞total sites you can keep
90days of visitor analytics retention

Updating an existing site does not use the daily new-site allowance. Each upload can contain up to 1,000 files / 50 MiB. Pagey also applies its own request and upload rate limits.

What Pagey does not run

Hosted sites are static: HTML, CSS, JavaScript, images, fonts, and other public assets. There is no Node.js, PHP, SSR, or custom API server.

Need a form backend? Use Pagey’s hosted forms — create one from ChatGPT, embed the iframe, and read the responses later.
